# 尺寸标注 / 标高 / 轴号

> 来源：用户提供的 `AGENTS_CAD.md`，并与 GB/T 50104 及制图教材的通行要求核对过。

## 三道外围尺寸的顺序（多来源一致，务必按此校核）

**由内到外，由小到大**：

| 道次 | 内容 | 距轮廓 |
|---|---|---|
| 第一道（最内） | 门窗洞口的宽度与定位 | 10mm |
| 第二道 | 定位轴线之间的距离（开间/进深） | 17mm |
| 第三道（最外） | 外包尺寸（建筑总长、总宽） | 24mm |

- 「最外面一道是总尺寸/外包尺寸，中间一道是轴线间距，最里面一道是门窗洞口」——
  三个独立来源表述一致。
- 平面图形不对称时，**四周均应标注尺寸**（`dimensions.side = "all"`）。
- **内墙上的门窗洞口另有局部尺寸链**，贴墙布置（`interior_openings`，默认开启）。
  这条链不受外层 10mm 规则约束——国标的 10mm 是针对图样**最外轮廓**的规定。
- 尺寸链的锚点只在**最外两道轴线之间**细分：不要把「外包面 = 轴线 ± 墙厚/2」也当锚点，
  否则会切出 120mm 这类碎段，文字在 1:50 下根本放不下。

## 尺寸标注（GB/T 50001 第11章）

- **尺寸界线**：细实线，从轮廓线/轴线引出，超出尺寸线 **2~3mm**
- **尺寸线**：细实线，与被标注线段平行
- **尺寸起止符号**：**45° 斜短线**，长度 **2~3mm**
- **尺寸数字**：写在尺寸线上方中部，**不被任何图线穿过**
- **互相平行的尺寸线**：从近到远排列，**小尺寸在内，大尺寸在外**
- **尺寸间距**：第一道离轮廓 **10mm**，第二道起间隔 **7mm**
- 单位：**全部毫米，不标注单位**

### 引擎实现参数

```
DIM_OFFSET_FIRST  = 10.0   # 第一道尺寸线距轮廓，mm
DIM_OFFSET_STEP   = 7.0    # 后续尺寸线间隔，mm
DIM_EXT_BEYOND    = 2.5    # 尺寸界线超出尺寸线，mm（取 2~3 中值）
DIM_TICK_LEN      = 2.5    # 45° 斜短线起止符号长度，mm
DIM_TEXT_HEIGHT   = 3.5    # 尺寸数字字高，mm
```

DXF 侧：

- 斜短线用 DIMSTYLE 的 `dimblk = "OBLIQUE"` / 或直接以 `DIMENSION` 实体的 `dimblk1` 指定 45° 刻度块；也可用 `dimtsz`（tick size）配合 `dimtad`。
- 尺寸数字必须落在尺寸线**上方中部**：`dimtad = 1`（above）、`dimtih = 0`、`dimjust = 0`（center）。
- 保证数字不被图线穿过：`dimtmove = 1`（移动文字，必要时加引出），`dimtoh = 0`。

## 标高符号（GB/T 50001 第11.8节）

- 等腰直角三角形，**直角朝下**
- 三角形高 **3mm**，引出水平线
- 标高数字写在**横线上方**
- 零点标高：`±0.000`
- 正数标高**不注 "+"**，如 `3.000`
- 负数标高**必须注 "-"**，如 `-0.450`
- 小数点后**三位**，单位**米**

### 数字格式化规则（`format_elevation`）

```python
def format_elevation(meters: float) -> str:
    s = f"{abs(meters):.3f}"
    if abs(meters) < 1e-9:
        return "±0.000"
    return s if meters > 0 else "-" + s
```

> 注意单位换算陷阱：标高输入用**米**，而平面坐标用**毫米**。引擎在绘制标高符号时固定用 3mm 三角形，不随图比例缩放；只有标高数值随实际高程变。

## 轴线编号（GB/T 50001 第8章 定位轴线）

- 轴线用**细点划线**
- 编号圆圈：**直径 8mm**，细实线
- 横向轴线：阿拉伯数字 **从左到右** `1, 2, 3...`
- 纵向轴线：大写拉丁字母 **从下到上** `A, B, C...`
- **不用字母 I、O、Z**（容易和 1、0、2 混淆）
- 详图轴线编号与原图对应，附加轴线用**分数**表示

### 编号序列生成

```python
LETTERS = "ABCDEFGHJKLMNPQRSTUVWXY"   # 已剔除 I / O / Z
```

## 门窗图例（平面图）

| 类型 | 画法 | 要点 |
|---|---|---|
| **门** | 门洞缺口 + **门扇线** + **90° 开启弧线** | 弧线交角一侧为合页侧；开启角度 90°/60°/45° 均可，同套图纸统一 |
| **窗** | **断开墙线** + **四条等距细实线** | 两条与墙面平齐（窗台线）、两条在墙厚三分点（玻璃线）；洞口两侧有封口线 |
| 无扇洞口 | 只断开墙体、画封口线 | 不画门扇与弧线 |
| 推拉门 | 两条错位平行矩形 | 不画开启弧线，标注推拉方向 |

> **窗也要断开墙线**——这一点容易漏。墙的粗线在洞口处必须断开，改由窗自身的
> 四条细线表达，否则墙线会「穿」过窗，与人工画法不符。
>
> 「四条等距细实线」的间距验算：240 墙 → 四条线在 −120/−40/+40/+120，间距 80mm；
> 门窗轮廓线按现行 GB/T 50104 用 **0.7b**（用户确认，见 `layers.md`）。

## 工程实施备忘（引擎侧）

**尺寸的几何块必须归到 DIM 图层。** AutoCAD 与 ezdxf 把尺寸线、尺寸界线、起止符号
渲染进一个匿名块，块内实体默认落在图层 0（颜色与线宽都 BYLAYER），于是既拿不到
DIM 图层该有的红色与线宽，部分预览渲染器甚至会把图层 0 的内容按背景色处理而完全看不见。
`annotation._finalize_dim()` 负责把这些实体显式改到 DIM 图层。

### 引擎实现参数

```
AXIS_CIRCLE_DIA   = 8.0    # 轴号圆圈直径，mm
AXIS_BUBBLE_TEXT  = 3.5    # 轴号数字/字母字高，mm（必须落在字高系列内）
AXIS_LINETYPE     = "CENTER"
AXIS_EXTEND       = 34.0   # 轴线超出最外轮廓的延伸量，**图纸毫米**
AXIS_EXTEND_MIN   = 34.0   # 安全下限 = 最外侧尺寸链 24mm + 10mm 净距
```

> **轴号与尺寸链的净距是必须保证的**：三道路尺寸链最外侧在 24mm 处，
> 若轴线只延伸 25mm，轴号圆圈（直径 8mm）会与总尺寸链的 45° 起止符号重叠。
> 引擎会强制把小于 34mm 的 `extend` 提升到安全值并给出提示。

> 注意单位口径：`extend` 是**图纸毫米**（出图后纸面上的长度），引擎会乘比例分母后落到模型空间。
> 凡是「国标规定了具体毫米数」的量（线宽、字高、标注偏移、填充间距、轴号直径、标高三角形高、
> 轴线延伸），一律按图纸毫米处理；只有建筑自身的尺寸（墙长、开间、洞口宽）才是模型毫米。
