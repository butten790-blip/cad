## 执行依据

- GB/T 50001-2017 《房屋建筑制图统一标准》
- GB/T 50104-2010 《建筑制图标准》
- GB 50210-2018 《建筑装饰装修工程质量验收标准》

## 图纸幅面（GB/T 50001 第3.1节）

| 图幅 | 尺寸 (mm) |
|---|---|
| A0 | 841×1189 |
| A1 | 594×841 |
| A2 | 420×594 |
| A3 | 297×420 |
| A4 | 210×297 |

- 标题栏在**右下角**，会签栏在**左上角**。
- 图框线线宽：A0/A1 用 `b`；A2/A3/A4 用 `0.7b`。

## 线宽（GB/T 50001 第4章）

基本线宽 `b` 从以下选定：**1.4 / 1.0 / 0.7 / 0.5 mm**

线宽组（按图面复杂程度选一组）：

| 基本线宽 b | 0.7b | 0.5b | 0.25b |
|---|---|---|---|
| 1.4 | 1.0 | 0.7 | 0.35 |
| 1.0 | 0.7 | 0.5 | 0.25 |
| 0.7 | 0.5 | 0.35 | 0.18 |
| **0.5** | **0.35** | **0.25** | **0.13** |

> **室内设计图一般选 b = 0.5mm 组。**

线宽用途分配（**GB/T 50104-2010 表 2.1.2**）：

| 线宽 | 用途 |
|---|---|
| 粗线 `b` | 平、剖面图中被剖切的**主要**建筑构造（含构配件）轮廓线；立面外轮廓线；**剖切符号** |
| 中粗线 `0.7b` | 平、剖面图中被剖切的**次要**建筑构造轮廓线；构配件轮廓线；构造详图的一般轮廓线 |
| 中线 `0.5b` | 小于 0.7b 的图形线、**尺寸线、尺寸界限、索引符号、标高符号**、详图材料做法引出线、分界线 |
| 细线 `0.25b` | **图例填充线、家具线**、纹样线；中心线、对称线、**定位轴线**；折断线、波浪线 |

> 层次硬要求：粗 : 中粗 : 中 : 细 = **4 : 3 : 2 : 1**。
> 线宽组只有这四档，**不存在 0.18b / 0.13b 这类中间档**——图层的线宽系数只能取上表四值。
> 落地换算见 `layers.md`。

## 字体（GB/T 50001 第5章）

- 汉字：**长仿宋体**，高宽比约 **1 : 0.7**
- 字高系列（mm）：**3.5 / 5 / 7 / 10 / 14 / 20**
- 图名：7mm 或 10mm
- 说明文字：5mm
- 尺寸数字：3.5mm
- **最小字高不小于 2.5mm**
- 拉丁字母和数字：用单线简体或 Roman 字体

### 长仿宋的实现注意

国标长仿宋（高宽比 1:0.7）在 TTF 环境下没有通用免费字体可直接对应。三种可行做法：

1. 使用单线 SHX 字体（`hztxt.shx` / `tssdeng.shx` 等）——最接近国标观感，但需要字体文件随项目分发。
2. 使用 TTF 仿宋（如 `FangSong`），然后给文字设置 **宽度因子 0.7**（DXF 的 `TEXT`/`MTEXT` 支持 `width` 属性）——兼容性最好，推荐作为默认。
3. 使用 `txt.shx` + 大字体 `hztxt.shx` 组合。

引擎默认走方案 2：注册 `CAD_FANGSONG` 文字样式，`width = 0.7`。

## 比例（GB/T 50104）

| 图别 | 常用比例 |
|---|---|
| 总平面图 | 1:500、1:1000 |
| 平面图 | 1:50、1:100、1:150、1:200 |
| 立面图 | 1:50、1:100 |
| 剖面图 | 1:50、1:100 |
| 详图 | 1:1、1:2、1:5、1:10、1:20 |

> **室内设计常用：平面 1:50，立面 1:30，大样 1:10 / 1:5。**
> 建筑类平面图另常用 1:100（住宅平面最常规）。**比例必须与图幅配套选**：
> 图样（含轴号、尺寸链、图名）要放进「图框内净空减去右下角标题栏」的可用矩形，
> 放不下就必须降比例或增大图幅。引擎的版面校验会给出结论与建议比例。

## 图纸要素与画法（多来源一致的通行要求）

| 要素 | 要求 |
|---|---|
| **图名** | 写在**图的正下方**，图名下画一条**粗实线**以醒目 |
| **指北针** | **一层平面图必须画**。细实线，圆直径 24mm，指针尾部宽 3mm，指针头部注「北」 |
| **会签栏** | 左上角 |
| **标题栏** | 右下角 |
| **房间名称** | 平面图应注写房间名称或编号 |
| **剖切符号** | 只在底层平面图上标注（本引擎暂未实现，见扩展路线） |

## 六种空间交接与图线层级（GB/T 50104 配套要求）

- 平面图常用比例 1:50、1:100、1:200，另可选用 1:150、1:300。
- 被水平剖切到的墙、柱断面轮廓线用**粗实线 b**；门窗轮廓线用 **0.7b**；
  其余可见轮廓线用中实线 0.5b；**图例填充线、家具线用细实线 0.25b**。
- **墙交接的规范处理**：
  - L 形转角：外线对外线、内线对内线，形成 90° 直角闭合；
  - T 形交接：贯通墙开洞口让交接墙穿入，洞口宽度等于交接墙厚；
  - 十字交叉：交叉区域墙体线全部打通，形成完整贯通节点；
  - **承重墙（外墙、剪力墙）优先贯通不中断，轻质隔墙在交接处断开让行**。
- **绘图顺序**：先外墙 → 后内墙 → 后轻质隔墙，各层分图层；
  **先画连续墙体，再单独一步打断做洞口**。

> 门窗轮廓线按 GB/T 50104 取 **0.7b**，与图层表一致（用户 2026-10-16 确认）。

## 常用经验取值（**非规范值**，仅供起步参考）

> 来源：公开 CAD 建筑平面图教程与识图教材（2026-10-17 收录）。
> ⚠️ **这些是行业常见做法，不是国标强制值，也不适用于所有结构形式。**
> 本技能的纪律是「不把某张图的取值当通用前提」——下列数字只在**没有其他依据时**用于起步，
> 一旦有设计条件、结构形式或甲方要求，一律以后者为准。
