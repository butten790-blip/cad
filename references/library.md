### 调用规则

- 画平面图时优先从图库中找对应图块插入，保持图例统一
- 找不到对应图块时再自己画，图形要按国标比例画
- 家具尺寸参考：床 `1800×2000`、沙发 `2200×900`、餐桌 `1600×900`、茶几 `1200×600`

## 引擎侧接入方式

1. 下载并解包图库到 `assets/blocks/`，按分类建子目录（`assets/blocks/宾馆/`、`assets/blocks/茶几/` …）。
2. 建立索引文件 `assets/blocks/index.json`，结构为 `{ "<中文图块名>": "<相对路径> }`。
3. `spec` 中通过 `furniture[].block` 引用图块名，引擎按索引查找 DWG/DXF 并插入到 `FURN` 图层。
4. **DWG 不能直接被 ezdxf 读取**，需要先用 ODA File Converter 批量转 DXF。转换步骤见 `SKILL.md` 的"图库预处理"。

## 平面图常用图例速查（补充）

> 来源：灵加教育《平面图图例大全》2026-10-17 收录。墙与门窗的画法见 `annotation.md`；
> 本表只列蓝图里常出现、而技能原先没写的图例。

| 图例 | 画法要点 | 归层 |
|---|---|---|
| **飘窗** | **U 形**——三面都是窗（正面 + 两个侧面），三边均画窗的细实线，凸出外墙 | `WIN-DOOR` |
| **烟道** | 小矩形，**内画两条对角线**（或加斜线）；定位在厨房、卫生间墙角 | `WALL-STR` 或 `HATCH` |
| **空调外机位** | 矩形**内画交叉对角线**，位于外墙预留平台 | 新建 `SITE` 或 `FURN` |
| **排水管 / 立管** | 小圆（直径约 100~150mm 实际管径），用细实线圆表示 | `WATER` |
| **栏杆** | 阳台、楼梯临空侧的**细实线**（单线或双线），不带填充 | `SITE` 或 `WIN-DOOR` |
| **检修口 / 预留洞** | **虚线**矩形（见 `annotation.md` 洞口一节） | `WALL-PAR` 线型或 `HATCH` |
| **电视机** | 细横线 + 两侧小三角（表示挂墙方向） | `FURN` |
| **衣柜** | 矩形 + 内部斜线（挂衣杆），深度 600 | `FURN` |

> 家具、洁具的**内部细节线**（衣柜斜线、灶眼、盆沿）统一用 `0.25b` 细线——
> 国标表 2.1.2 明确"家具线、图例线"属细线档。
