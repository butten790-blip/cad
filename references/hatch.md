# 填充图例（GB/T 50104）

> 来源：用户提供的 `AGENTS_CAD.md`。**材料填充**统一放在 `HATCH` 图层。
> **线宽已于 2026-10-17 按国标改为 `0.25b`**（原表为 0.13b）——
> GB/T 50104 表 2.1.2：图例填充线、纹样线用细线 **0.25b**。
>
> ⚠️ 注意区分两种填充：
> **材料填充**（地砖、木地板…）→ `HATCH` 层；
> **剖切填充**（墙、柱的 poché 实心黑）→ **`WALL-POC` 层**，见下节。

## 剪力墙 poché（实心填充）

**最容易搞错的一条**：平面图里"实心黑色"的墙 = **钢筋混凝土剪力墙的 poché（剖切图例）**。
它决定的不是一个填充样式，而是这个构件到底是**结构墙**还是**隔墙**：

| 图示 | 是什么 | 几何来源 | 归层 | spec |
|---|---|---|---|---|
| 轮廓线 + **实心黑填充** | 钢筋混凝土**剪力墙**（承重 / 抗震墙） | 取**轮廓**；填充另外加 | `WALL-STR` + `HATCH` | `walls[].type="structural"` |
| 双线轮廓，**无填充** | 砌体**隔墙 / 填充墙** | 两条平行轮廓线 | `WALL-PAR` | `walls[].type="partition"` |

> **铁律：几何永远来自轮廓线，填充只是图例。**
> 不要把填充的包围盒（bbox）当成墙——L 形、T 形组合墙的 bbox 会把整段吃掉
> （这就是曾经"墙体不完整"的根因之一，见 `pitfalls.md` A4/A5）。

DXF 落法（引擎已实现，见 `cadlib/hatch.py` 的 `add_solid_poch()`）：
**轮廓照常落在 `WALL-STR`，填充单独落在 `WALL-POC`**，两者是两类独立实体。

```python
# ① 轮廓：直线 / 多段线命令画的边界（墙的几何）
msp.add_lwpolyline(墙轮廓顶点, close=True, dxfattribs={"layer": "WALL-STR"})

# ② 填充：填充命令（HATCH）叠在轮廓内，单独图层
add_solid_poch(msp, 实墙段顶点)      # layer 默认 "WALL-POC"
```

**为什么必须分开图层**：
- 轮廓是**几何**、填充只是**图例**。关掉 `WALL-POC` 应当仍能看到完整的墙轮廓；
- 打印时才能单独淡化/关闭填充，检查时能一眼分清"哪条是墙的边界"；
- 塞进同一层就做不到上面两件事。

**填充范围是「实墙段」**：引擎按 `solids`（扣除洞口后的墙段）逐段填充，
所以门窗洞口处**不涂黑**——这也正是手工画法的样子。

## 材料填充图例

| 材料 | 填充方式 |
|---|---|
| 砖墙剖切 | 45° 斜线，间距 2~4mm |
| 混凝土剖切 | 三角形加小点 |
| 石材/地砖 | 方格网 |
| 木地板 | 45° 斜线，间距大 |
| 玻璃 | 45° 斜线，间距大，两条平行线 |
| 防水层 | 小点 |
| 保温材料 | 锯齿形 |

## 映射到 DXF HATCH pattern

| 材料 key | DXF pattern 名 | scale 起点 | 备注 |
|---|---|---|---|
| `brick` | `ANSI31` | 参考间距 3.0 | 45° 斜线；调 `scale` 使间距落在 2~4mm |
| `concrete` | `AR-CONC` | 1.0 | 三角形+小点，自定义 PAT 更接近国标 |
| `stone_tile` | `NET` | 1.0 | 方格网 |
| `wood_floor` | `ANSI31` | 8.0 | 同 45° 斜线，放大间距 |
| `glass` | 自定义 `GLASS`（推荐） | 1.0 | 原表"45°斜线+两条平行线"，标准 pattern 无直接对应，需自定义 PAT |
| `waterproof` | `DOTS` | 1.0 | 小点 |
| `insulation` | 自定义 `INSUL` | 1.0 | 锯齿形，需自定义 PAT |

### 自定义 PAT 说明

`GLASS` 与 `INSUL` 标准库没有，需在 `scripts/cadlib/hatch.py` 里以 `set_pattern_fill(..., definition=[...])` 形式传入 pattern 定义行，或随技能分发 `.pat` 文件后加载。

填充填充密度由 `scale` 控制，**单位是 DXF 图纸单位（此处即 mm）**，因此 1:50 出图时若在模型空间按实际尺寸绘制，`scale` 直接取毫米级数值即可，不需要再乘比例。
