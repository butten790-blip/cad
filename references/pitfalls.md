# 踩坑与对策登记表（实测）

> **纪律**：每踩一个坑，就在此登记一条「现象 → 根因 → 对策」，并标严重度。
> **开工前先扫本表**，命中直接套对策，不要重新踩一遍。
> 严重度：🔴 会让产物不可用 / 🟠 会明显返工 / 🟡 影响观感或效率。

## A. 参考图摄取与复刻（`scripts/ingest/`）

| # | 现象 | 根因 | 对策 | 级别 |
|---|---|---|---|---|
| A1 | 复刻出来"墙体不完整、该有的都没有" | 把**矢量 PDF** 渲染成位图再靠肉眼估几何 | 先判输入：`get_drawings()` 路径多、`get_images()` 为空 ⇒ 矢量。**矢量直接读路径** | 🔴 |
| A2 | 复刻尺寸整体差 ~100~150 倍 | PDF 的 `rect/point` 单位是 **pt**，被当成 mm 用 | 换算模型前一律 `pt * 25.4 / 72` 转 mm | 🔴 |
| A3 | 复刻出来的图量不出真实尺寸 | 没有标定，只是纸面毫米 | 用**最大总尺寸**反推 `k`：量两端界线纸面 Δx，`k = Δx / 总尺寸`；再定 origin | 🔴 |
| A4 | 把"实心黑填充"当成墙；漏掉无填充的隔墙 | 误以为"填充=墙"。实为 **剪力墙 poché** | **几何取轮廓**；填充只是图例。有填充=剪力墙(`structural`/`WALL-STR`)，无填充双线=隔墙(`partition`/`WALL-PAR`) | 🔴 |
| A5 | 组合墙（L/T 形）整段丢失 | 用填充的 **bbox** 判墙，组合墙 bbox 过大被厚度过滤掉 | 判墙要用**轮廓多段线/合并后的墙段**，不要用单个填充 bbox | 🔴 |
| A6 | 剪力墙识别结果 = 0 | PDF **y 轴向下**，`my(r.y0) - my(r.y1)` 得到负高度 | 统一取 `y0=min(my(..)), y1=max(my(..))`，高度恒正 | 🟠 |
| A7 | 隔墙数量虚高（实测 280 段，混入填充纹理、家具边、踏步） | 只按"双线配对 + 中间无填充"判，等间距平行线族混了进来 | 加三条硬约束：①每条线长 **≥500**；②两线**两端对齐 ≤220**；③**全局线族识别**（连续 ≥3 条、间距相近 60~200 ⇒ 填充/踏步，整组剔除）。实测 **280 → 43** | ✅ 已解决 |
| A8 | 位图复刻里的文字全丢 | 位图路线未接 OCR | 位图文字需 OCR（RapidOCR/PaddleOCR）或人工补录；**矢量 PDF 直接读文本层，无此问题** | 🟡 |
| A9 | 页边尺寸链/图框/说明区被当成墙 | 未限定建筑主体范围 | 摄取前用 `--x0/--y0` 与 bbox 把图框、尺寸链、门窗表排除 | 🟡 |
| A10 | 换一张"非本技能约定"的图就全乱（不同标准/墙体画法/无尺寸/非平面图） | 把本技能的取值（1:100、墙厚 200、实心填充墙）当成了**通用前提** | **任何参考图先跑 `probe.py` 体检**；比例/墙体表示法探测不出**必须问用户**；理解不了退回**忠实转绘**兜底 | 🔴 |
| A11 | 照着识图教材的画法落笔，结果与国标冲突（如把索引符号画成**菱形**、把洞口一律画成虚线） | 教材为便于辨识做了**简化示意**，不是规范值 | 教材只用来**发现遗漏**，落笔一律回查国标原文（GB/T 50001 / GB/T 50104）。本次据此纠正了整套线宽体系并补齐索引符号 | 🟠 |

## B. 出图引擎（`scripts/cadlib/`）

| # | 现象 | 根因 | 对策 | 级别 |
|---|---|---|---|---|
| B1 | 线宽层次全糊、分不出粗细 | `to_dxf_lineweight` 若改成"向上吸附"会撞档 | 保持**取最近值**：0.065→5、0.09→9、0.125→13、0.25→25、0.35→35、0.5→50 | 🟠 |
| B2 | 轴号画成点划圆圈 | AXIS 层是 CENTER 点划线，圆圈继承了它 | 轴号圆圈**显式声明 `CONTINUOUS`** | 🟠 |
| B3 | 预览里尺寸线/界线消失，只剩数字 | 尺寸几何在匿名块里、落在**图层 0** | `annotation._finalize_dim()` 显式把几何改回 DIM 层 | 🟠 |
| B4 | 改了 .py 但出图还是旧值 | `__pycache__` 缓存 | 改完先 `rm -rf __pycache__ cadlib/__pycache__` 再跑 | 🟠 |
| B5 | 统计实体时莫名空集合 | `e.dxf.layer` 对部分实体会抛异常被吞 | 用 `e.dxf.get("layer", "")` | 🟡 |
| B6 | 预览里墙线/图框/图名全看不见 | ACI 7(白) 在黑底渲染器上画到白纸=隐形 | `export.py` 必须显式 `BackgroundPolicy.WHITE`；**不要**再叠加 `COLOR_SWAP_BW` | 🟠 |
| B7 | 面积上标「²」变方框 | 仿宋无 U+00B2 字形 | 单独绘小号「2」并上抬，不依赖字体上标 | 🟡 |
| B8 | 预览里「图」字被填成黑块 | 字形轮廓用 nonzero 规则填充 | 渲染前临时换到干净字体（msyh/simhei），DXF 内仍是仿宋 | 🟡 |
| B9 | 轴线看着是实线，没有点划 | `$LTSCALE` 未随比例设置 | `$LTSCALE` = 比例分母 | 🟡 |
| B10 | 两次出图哈希对不上 | 三来源：ezdxf 元数据/时间、Python 哈希随机化、`$LTSCALE` | 冻结元数据 + 入口以 `PYTHONHASHSEED=0` 重启自身 + `$LTSCALE` 随比例 | 🟠 |
| B11 | 填充密到糊成一片 / 完全看不见 | 填充间距按模型毫米用了，没乘比例分母 | `add_area_hatch(..., scale=ctx.scale)` | 🟠 |
| B12 | 线宽层次与国标不符：**墙比门窗还细**，且出现 0.18b / 0.13b 这类档位 | 图层表沿用自定义系数，从未与 GB/T 50104 表 2.1.2 逐条核对 | 线宽系数**只允许四档**：`b / 0.7b / 0.5b / 0.25b`。分配：墙=`b`、隔墙/门窗=`0.7b`、尺寸=`0.5b`、图例·家具·轴线=`0.25b`。实测 DXF 值 50/35/25/13 | ✅ 已解决 |
| B13 | 图上有详图要索引，却没有索引符号可用 | 引擎未实现索引/详图符号 | `cadlib/symbols.py` 已实现（GB/T 50001 第7.2节）：索引符号 10mm 细实线圆+水平直径；详图符号 14mm 粗实线圆；零件编号 5mm 细线圆。spec 字段 `index_symbols` / `detail_symbols` / `part_marks` | ✅ 已解决 |
| B14 | 墙体**轮廓**与剖切**填充**画在同一图层：关掉填充层连墙一起消失；想调填充样式却动到了墙的几何 | 两类性质不同的实体共用一个图层 | **轮廓**（`LINE`/`PLINE`=几何）归 `WALL-STR`/`WALL-PAR`；**剖切填充**（`HATCH`=图例）独立成 `WALL-POC`。引擎：`hatch.add_solid_poch()`；复刻：`classify_walls.py` 同步分层。实测 WALL-STR 只剩 16 条多段线、WALL-POC 收到 12 个实心填充 | ✅ 已解决 |

## C. 环境与依赖安装（本机实测）

| # | 现象 | 根因 | 对策 | 级别 |
|---|---|---|---|---|
| C1 | `pip install` 报 "No matching distribution / from versions: none" | 本机 pip 走系统代理，索引解析失败 | **curl 直下 wheel** 到本地，再 `pip install --no-index <wheel绝对路径>` | 🟠 |
| C2 | 装完 ezdxf 一导入就崩 | numpy 装成了 cp312 的 wheel | numpy **必须取 cp313** 的 wheel | 🔴 |
| C3 | opencv 报 `numpy<2.3` 不满足 | 本机 numpy 2.5.4，opencv 声明上限 | `pip install --no-index --no-deps <opencv wheel>`（同属 numpy 2.x，ABI 兼容，实测可用） | 🟡 |
| C4 | `pip install --no-index --find-links <目录> <包名>` 报 No such file | 本机 pip 会去一个不存在的缓存目录解析 | 直接给 **wheel 绝对路径**，不要用 `--find-links` | 🟡 |

## 一句话总纲

1. **先体检再动手**（`probe.py`），参考图不一定遵守本技能约定。
2. **先判输入，再选工具**（矢量 ≠ 位图，别把矢量渲染成图再目测）。
3. **用尺寸标注标定**，否则没有 1:1；探测不出就**问用户**。
4. **轮廓是几何，填充是图例**（剪力墙 poché）。
5. **理解不了就退回忠实转绘**，保证"至少能拿到一份可编辑的图"。
6. **改 .py 先清 `__pycache__`**。
7. **出图必须字节可复现**（元数据 + 哈希种子 + LTSCALE）。
