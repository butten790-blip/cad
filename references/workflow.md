# 绘图流程 SOP（软件操作层）

> 来源：公开 CAD 建筑平面图教程（易档网《CAD建筑平面图绘图步骤》、敬慕百科《cad建筑平面图怎么画》）
> 与 GB/T 50104-2010 通行做法核对后整理。**本文只讲"在 CAD 里怎么操作"**；
> 取值规范见 `standards.md`，图层见 `layers.md`，标注见 `annotation.md`。
>
> ⚠️ 公开教程里的"经验取值"（外墙 240、内墙 120、开间 3300/3600 等）**不是规范值**，
> 只是某类住宅的常见做法，**不得当默认前提**——按实际工程定。

## 一、绘图前环境设置（顺序不要颠倒）

| 步骤 | 命令 | 设置 |
|---|---|---|
| 1 | `UNITS` | 长度类型**小数**；精度 **0**；单位 **毫米** |
| 2 | `LIMITS` | 左下 `0,0`；右上按图幅：A3 `420,297`、A4 `297,210`、A2 `594,420`、A1 `841,594`、A0 `1189,841` |
| 3 | `ZOOM` → `A` | 全屏显示图幅 |
| 4 | 状态开关 | 打开**正交**、**对象捕捉**、**对象追踪**；捕捉勾选 **端点 / 中点 / 交点 / 垂足** |
| 5 | `LAYER` | 按 `layers.md` 建图层表（名称 / 线宽 / 颜色 / 线型） |

> 精度的含义：`UNITS` 的精度是**显示精度**，不是尺寸精度。设 0 表示尺寸数字显示为整数毫米。

## 二、图框与标题栏

- 在**图框图层**按 **1:1（纸面毫米）** 绘制，标题栏在**右下角**。
- 国标图框线线宽：A0/A1 用 `b`；A2/A3/A4 用 `0.7b`。

## 三、"放大倍数" = 比例分母（关键概念）

模型空间按**真实毫米**画（墙长 3000 就画 3000），出图时按比例缩小，所以**比例分母**决定了：

| 受"放大倍数"影响的量 | 关系 |
|---|---|
| 文字字高 | 纸面字高 × 分母 = 模型空间字高 |
| 标注全局比例 | = 分母 |
| 线型比例 `$LTSCALE` | = 分母（否则点划线在图上变成实线） |
| 填充图案比例 | = 分母（否则填充密到糊成一片或看不见） |
| 打印比例 | = **分母的倒数**（1:50 → 打印时选 1:50） |

> 这正是本引擎的**单位口径**：几何用模型毫米，凡国标规定了具体毫米数的量
> （线宽、字高、标注偏移、填充间距、轴号直径、标高三角形高、轴线延伸）
> 一律按**图纸毫米**，由引擎乘分母。改任何绘制模块前先确认口径。

## 四、绘图顺序

1. **轴线层** → 画定位轴线（点划线），`OFFSET` 偏移出全部轴网，`TRIM` 修剪
2. **定义多线样式**（按实际墙厚：剪力墙 / 砌体墙 / 隔墙各一套）
3. **墙线层** → 沿轴网画墙；**门窗层** → 开洞、插门窗图块
4. **家具层** → 以插入图块的方式布置家具、洁具
5. **细部** → 楼梯（踏步宽 ≈260、高 ≈150 的经验值）、阳台、飘窗、烟道、管道井
6. 清理 → 检查 → 标注 → 出图

> **墙交接的处理**见 `standards.md`「六种空间交接与图线层级」：
> L 形、T 形、十字各有规范画法；承重墙优先贯通，轻质隔墙在交接处断开让行。
> 不要用"单线偏移"拼墙，交接处线条会互相压线、缺口。

## 五、文字样式

- **长仿宋**：`FangSong`（TTF 仿宋）+ **宽度因子 0.7**，或用 SHX 大字体 `hztxt.shx`。
- 字高取自字高系列 **3.5 / 5 / 7 / 10 / 14 / 20**，最小不小于 2.5mm。
- 中文 CAD 图里文字用 SHX 单线字体在旧版软件中最稳；TTF 更通用但要设宽度因子。

## 六、尺寸标注样式的软件设置

| 项目 | 设置 |
|---|---|
| 箭头 | **建筑标记**（45° 斜短线），不是实心箭头 |
| 文字 | **ISO 标准**（在尺寸线上方中部） |
| 全局比例 | = **放大倍数（比例分母）** |
| 主单位精度 | **0**（整数毫米） |
| 测量单位比例 | 只有**同一张图混排不同比例**时才用 |

- 三道尺寸由内到外：**洞口 → 轴线间距 → 外包装**，间距 10mm + 7mm（见 `annotation.md`）。
- 现代做法：**不分解标注**（保持 DIMENSION 实体可编辑），分解会丢失关联性。

## 七、出图与打印

- 打印比例 = **放大倍数的倒数**。
- 选**居中打印** + **窗口**框选图框两对角；先**完全预览**确认无误再打印。
- 存盘交付：另存为**较低版本 DWG**（如 AutoCAD 2008 格式）以兼容他人。
- 电子交付另导 PDF；输出图片用"输出/EXPORT"。

## 八、交付前自检

| # | 检查 | 手段 |
|---|---|---|
| 1 | 尺寸数据有无偏差 | `DIST` 抽查关键尺寸 |
| 2 | 图层 / 线型 / 标注样式是否统一 | 图层管理器 + 特性匹配 |
| 3 | 有无开口未闭合、冗余图元 | 目视 + `PU` 清理垃圾数据 |
| 4 | 图框标题栏字段是否填全 | 见 `checklist.md` 第 9 项 |
| 5 | 轴号有无 I / O / Z | 见 `checklist.md` 第 6 项 |

> 本技能的 `scripts/validate.py` 已把上表可自动化的部分实现为十一项质检，
> 交付前跑一次；`ERROR` 必须修复，`WARN` 需人工确认。

## 九、图层颜色 / 线型的"软件约定"与国标的关系

公开教程常见的颜色约定（轴网红、墙黄、门窗蓝、标注绿）是**为了在屏幕上区分图元**，
属于**软件操作习惯**，不是国标。国标只规定**线宽层级**与**线型**（点划线/虚线/实线）。

> 本技能的 `layers.md` 是**用户确认过的图幅表**，颜色以它为准——
> 例如 `AXIS` 已按审图意见改为**白/黑**（轴线是辅助线、轴号是细实线圆圈），
> 而不是教程里的红色。**遇冲突以 `layers.md` 为准。**
