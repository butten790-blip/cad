# 图层设置（室内设计常用）

> 来源：用户提供的 `AGENTS_CAD.md` 原表。
>
> **线宽系数已于 2026-10-17 按 GB/T 50104-2010 表 2.1.2 归正为 `b / 0.7b / 0.5b / 0.25b` 四档**，
> 原因与影响见文末「本次修订」。颜色与图层名保持用户原表不变。
>
> **一处颜色早已按审图意见调整**：`AXIS` 由「红」改为「白/黑」(ACI 7)。
> 理由：轴线是辅助线、轴号是标注元素，出图时都应是**细黑线**；
> 轴号圆圈更要求**细实线**（GB/T 50001 第8章），红色点划圆不符合。
> 若需恢复原表，只改 `cadlib/layers.py` 的 `LAYER_TABLE` 中 AXIS 那一行的颜色列。

| 图层名 | 线宽 | 颜色 | 线型 | 用途与国标依据 |
|---|---|---|---|---|
| `WALL-STR` | **`b`** | 白 | CONTINUOUS | 结构墙/承重墙：被剖切的**主要**建筑构造轮廓线 |
| `WALL-POC` | **`0.25b`** | 白 | CONTINUOUS | **结构墙/柱的剖切填充**（poché，实心黑）。★ 独立图层，绝不与轮廓线混画 |
| `WALL-PAR` | **`0.7b`** | 白 | CONTINUOUS | 隔墙/非承重墙：被剖切的**次要**建筑构造轮廓线 |
| `STAIR` | **`0.7b`** | 白 | CONTINUOUS | 楼梯踏步与上下行方向线（被剖切的次要构件） |
| `WIN-DOOR` | **`0.7b`** | 黄 | CONTINUOUS | 门窗洞口和图例（被剖切的次要构配件） |
| `DIM` | **`0.5b`** | 红 | CONTINUOUS | 尺寸标注（尺寸线、尺寸界限） |

| `TEXT` | **`0.25b`** | 蓝 | CONTINUOUS | 文字说明 |
| `AXIS` | **`0.25b`** | **白/黑**（原为红） | CENTER | 定位轴线（细点画线）与轴号（细实线圆圈） |
| `ELEC` | **`0.25b`** | 黄 | DASHED | 电气线路（虚线） |

## 映射到 DXF 时的字段

| 列 | DXF 属性 | 说明 |
|---|---|---|
| 线宽 | `layer.dxf.lineweight` | 单位 1/100 mm。`b` 在 b=0.5 组下 = 0.5mm → `50` |
| 颜色 | `layer.dxf.color` | ACI 色号。白=`7`、黄=`2`、灰=`8`、红=`1`、蓝=`5`、绿=`3`、8号灰=`8` |
| 线型 | `layer.dxf.linetype` | `CONTINUOUS` / `CENTER` / `DASHED` |
| 用途 | — | 仅注释，写入图层描述 |

### 线宽换算（b = 0.5 组，DXF lineweight 值 = mm × 100）

| 系数 | 实际线宽 (mm) | DXF lineweight | 本层用法 |
|---|---|---|---|
| `b` | 0.5 | 50 | WALL-STR |
| `0.7b` | 0.35 | 35 | WALL-PAR / STAIR / WIN-DOOR |
| `0.5b` | 0.25 | 25 | DIM |
| `0.25b` | 0.125 | 13 | WALL-POC / FURN / HATCH / TEXT / AXIS / ELEC / WATER |

> 四档在 DXF 合法线宽值里**逐档一一对应**（13 / 25 / 35 / 50），换算用「取最近值」。
> **不要改成「向上吸附」**：那会把 `0.25b` 抬到 25，与 `0.5b` 撞档，层次就塌了。
> 粗 : 中粗 : 中 : 细 = **4 : 3 : 2 : 1**，这是国标对线宽层次的硬要求。
>
> ACI 色号对照：1红 2黄 3绿 4青 5蓝 6品红 7白/黑 8灰 9浅灰。

## 线型

| 图层 | 线型 | 说明 |
|---|---|---|
| `AXIS` | `CENTER`（点划线） | 轴线必备（GB/T 50104 表 2.1.2：中心线、对称线、定位轴线用**细**单点长画线 0.25b） |
| `ELEC` | `DASHED`（虚线） | 电气线路 |
| `WATER` | `CONTINUOUS` | 双线用两条平行实线表达，不靠线型 |
| 其余 | `CONTINUOUS` | — |

> **例外**：AXIS 图层是 CENTER 线型，但**轴号圆圈必须显式指定 `CONTINUOUS`**，
> 否则会继承父图层的点划线型，被画成点划圆。轴号圆圈要求细实线。
> 图框、引线等辅助元素同理，落在非 CONTINUOUS 图层上时要显式声明线型。

## 本次修订（2026-10-17，按 GB/T 50104-2010 表 2.1.2）

原表的线宽系数是 `0.5b / 0.25b / 0.18b / 0.13b`，有两处与国标冲突：

1. **`0.18b` 与 `0.13b` 不在国标线宽组内**。国标的线宽组只有四档：
   `b / 0.7b / 0.5b / 0.25b`（b=0.5 组即 0.5 / 0.35 / 0.25 / 0.125 mm）。
   原表的 0.18b(=0.09) 与 0.13b(=0.065) 是自定义档，**已归并到 0.25b**。
2. **原表把墙给到 `0.5b`（0.25mm），比门窗的 `0.7b`（0.35mm）还细**——
   与国标「平、剖面图中被剖切的**主要**建筑构造轮廓线用 **b**」直接相悖。
   现按国标把 `WALL-STR` 提到 **`b`**，成为全图最粗的一档。

同时按国标补齐了两条明确分配：

- **尺寸线、尺寸界限**属 **`0.5b`**（国标表 2.1.2 明列），故 `DIM` 由 0.13b 提到 0.5b；
- **图例填充线、家具线**属 **`0.25b`**，`FURN` / `HATCH` 统一到 0.25b。

> ⚠️ **影响**：这是线宽体系的整体变更，`scripts/cadlib/layers.py` 的 `LAYER_TABLE` 已同步，
> **此前出过的图纸需要重出**才能呈现新的线宽层次。

## 轮廓与填充必须分开图层（`WALL-POC`，2026-10-17 新增）

### 墙体在 CAD 里是怎么画出来的

**墙 = 直线 / 多段线命令画的轮廓；实心黑 = 叠在上面的填充命令（HATCH）。**
两者是**两个独立的命令、两类独立的实体**，不是一回事：

| | 用什么画 | 落在哪层 | 关掉这层会怎样 |
|---|---|---|---|
| 墙的**几何** | 直线 / 多段线（`LINE` / `PLINE`） | `WALL-STR` / `WALL-PAR` | 墙**消失**（几何在这里） |
| 剖切**填充** | 填充命令（`HATCH`） | **`WALL-POC`** | 只剩空心轮廓 —— 墙仍在，只是没有 poché |

所以：

- **几何永远来自轮廓线**，填充只是图例（poché）。**不要拿填充的包围盒当墙。**
- 剪力墙（钢筋混凝土承重/抗震墙）有填充；砌体隔墙**无填充**，是双线。
- 填充单独一层的好处：打印时可单独淡化或关闭填充、出图检查时能一眼分清"哪条是墙的边界"。

引擎落点：
- `cadlib/hatch.py` → `add_solid_poch()` 只负责"填"；
- `cadlib/geometry.py` → `draw_walls()` 先出轮廓（`outline` 并集边界），再按**实墙段**（扣除洞口）加填充；
- `cadlib/structure.py` → 结构柱的涂黑同样走 `WALL-POC`；
- `scripts/ingest/classify_walls.py` → 复刻参考图时，剪力墙的轮廓与填充也分层落。

## GB/T 50001-2017 第13章：图层命名规定（对照）

标准原文要点（第 13.0.1、13.0.2 条）：

1. 图层宜按**用途、设计阶段、专业属性、使用对象**组织，工程上要有明确逻辑关系；
2. 图层名宜用**汉字、英文字母、数字、连字符 `-`** 的组合，但**汉字与英文字母不得混用**；
3. **同一工程必须用统一的命名格式**，且名称自始至终保持不变；
4. 命名采用**分级形式**：`专业代码-主代码-次代码1-次代码2-状态代码`（2~5 级，各级用 `-` 分隔）
   - **专业代码**：1 个字符（建筑 = `A`）
   - **主代码 / 次代码**：宜为 4 个字符
   - **状态代码**：1 个字符
5. 图层名宜选用标准**附录 B** 所列的常用图层名称。

### 本技能图层表与该标准的对照

本表沿用`AGENTS_CAD.md`的既有命名（**英文、连字符分隔、同级语义可读**），
已满足 13.0.1 的"统一格式 / 不混用汉字"与 13.0.2 的"分级 + 连字符"要求；
若要**严格**套用带专业代码的完整格式（如 `A-WALL-STR`），把每层的 `A-` 前缀补上即可，
**图层语义与线宽分配不变**。

> 采用同一格式的图元必须归到同一图层：**不同性质的图元不共层**（这是本节 `WALL-POC` 单独成层的原因）。
